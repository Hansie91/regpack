## Decisions made by this plan (reversible, with reasons)

- **D-W1 Layout.** `regpack-flow` packages `dev.regpack.flow.{ingest,evidence,enrich,validate,report,output,send,feedback,xml}`; typed readers in `regpack-pack` `dev.regpack.pack.report`; the derive step in `regpack-engine` `dev.regpack.engine.pack`; identifiers in `regpack-model` `dev.regpack.model.ident`; composition, simulator, CLI in `regpack-sandbox` `dev.regpack.sandbox`. Flow depends on the ports, never on `regpack-evidence`; only the sandbox names `DurableSeal` and wires the encrypting store.
- **D-W2 Stage order per batch (spec 7.2, 7.5, 6.3).** Land (encrypted, manifest row, retention row) and PUT `BatchAdmitted`; `commitIngest`; acknowledge the source (the connector then moves the file); enrich and put the snapshot; decide, derive, validate; one `commitReportable` per batch with `completesOutbox`. A crash after `commitIngest` is repaired by `recoverPending`; a redelivery is a no-op. Whether a batch still needs deciding is the state of its DECIDE_BATCH outbox item (PENDING), never the redelivery flag: `Flow.ingest()` and every `Flow.tick()` end with `reportFlow.recoverPending()`, which handles each pending item in its own try block; on an exception it writes one DQ item DECIDE_FAILED (exception class name only) and goes on, the failed item stays PENDING for the next sweep.
- **D-W3 DQ items** are immutable JSON objects `Dq(kind, scope, line, column, code, rule, layer, severity)`, never a value of the record; key `dq/<scope>/<kind>-<line>-<rule-or-code>` (the rule id for a VALIDATION_BLOCKER, the `code` for every other kind); `scope` is the batch digest hex for ingest and decide items, the SHA-256 hex of the answer bytes for feedback items, the SHA-256 hex of the file name for waiting and redelivered-file items, `d<delivery id, 10 digits>` for delivery items (line 0). No ordinal, counter or timestamp: the same item written twice is the same key and bytes (ALREADY_PRESENT_IDENTICAL), so a replay writes nothing new. A VALIDATION_BLOCKER has one item per finding. BATCH_REJECTED and BATCH_QUARANTINED carry the note RELEASE_NEEDS_NEW_BYTES in `rule`. Kinds: BATCH_REJECTED, BATCH_QUARANTINED, BATCH_SUMMARY, COMPLETION_PENDING, RECORD_QUARANTINED, FILE_REDELIVERED, STALE_VERSION, SOURCE_CONFLICT, VERSION_CONFLICT, UNDETERMINED_DECISION, VALIDATION_BLOCKER, WITHDRAWAL_REQUIRED, L6_FAILED, UNMATCHED_FEEDBACK, FEEDBACK_ANOMALY, FEEDBACK_CONFLICT, SEND_ANOMALY, DECIDE_FAILED, VALIDATOR_DEFECT. Plain namespace (no personal data by construction).
- **D-W4 Mapping** (strict YAML; digest = SHA-256 of `Json.canonical` of the parsed tree; `DecisionContext.mappingVersion` = `<id>@<hex>`): keys `mapping`, `format`, `source_record_id`, `source_version`, `event_identity`, `control_totals`, `expected_population` (`none`), `absence`, `time`, `columns` (each `column` or `constant`, `to`, and `enum` or `cast`); casts `STRING`, `DECIMAL`, `BOOLEAN`, `INSTANT_UTC`; no business logic; an `event_identity` other than (firm.lei, venue.mic, venue.executionId) is refused. The column `exec_within` declares `enum: [ALGO-1, ALGO-2, ALGO-3]`: any other value is Quarantined `ENUM`.
- **D-W5 Derive** rows `{id, field, when, value, rule_ref, cite}` compiled with the scope `Expression`; values rendered as strings (decimal plain, instant `isoMicros`, enum by name); a row whose `when` is false contributes no `DerivedField`: the field is absent from `Result.fields`, the body and the projection input; a failing row after a REPORT hit gives UNDETERMINED `EXEC_ERROR`.
- **D-W6 Context.** `PackRegime.contextFor(BatchInputs)` returns the base context with four caller-supplied components (`mappingVersion`, `firmProfileVersion`, `referenceSnapshotIds`, `enrichmentSnapshotIds`; key text, at most 64 entries); `requireOwnContext` accepts a difference in those four only.
- **D-W7 Report.** Body = `Json.canonical` of the derived fields plus `trn`; `logical_hash` = SHA-256 of it; TRN = `TrnDerivation.derive(kms, key, regime, identity, MARKET, 32)` (V4); action from the decision attribute `action` (`set:` on the scope rows, BRK-10); stored body = `BodyCipher.seal`; `executingLei` = firm LEI; `EndpointKey("SIMULATOR", "SELF", firmLei, "SIM")`, epoch 1, origin SOURCE.
- **D-W8 File drop.** `send` writes `staging/<name>.part` (next to, not inside, `outbox/`; a leftover part is first removed with `Files.deleteIfExists`, because after a crash it can be a second name of a delivered file and unlinking never touches that inode; then opened CREATE_NEW, WRITE, NOFOLLOW_LINKS, never TRUNCATE_EXISTING; forced to disk), calls the gate once, `Files.createLink(outbox/<name>, part)` (the delivery point; fails if present: REJECTED_DUPLICATE), deletes the part. A gate exception propagates unchanged and the part is deleted; UNKNOWN_OUTCOME is only for an I/O failure after the gate; a failure before the gate is FAILED_BEFORE_FIRST_BYTE. The profile says `upload: temp_name_then_rename`; `upload: direct` is refused in W1a. The transport keeps an in-process map fileId to fileName filled by `send`; `probe` (PRESENT if the file exists; the simulator never deletes) and `pollAcks` use it (an unknown fileId is ABSENT). fileName must match `[A-Za-z0-9][A-Za-z0-9._-]{0,63}` with no `..` or colon, else it is refused before any write. Answer name `ack-<6 digits>-<outbox file name without .xml>.xml`, published by the Simulator through `staging/` and `Files.createLink`, the number taken at publication (strictly increasing, also under `ack_delay`); `pollAcks`, `probe` and the Simulator ignore names that start with a dot and show an answer only when its `asOf` (the `endpointAsOf`, read through `SecureXml`) is not after `clock.now()`. A file that is not a DEMO document gets a file-level reject.
- **D-W9 Sender tick.** Renew or acquire the lease; release PREPARED deliveries (a waiting version goes PREPARED to BLOCKED and back). A PREPARED delivery is released when no earlier version of its business key is in PREPARED, BLOCKED, QUEUED, SENDING, AWAITING_ACK, PENDING_AT_ENDPOINT, IN_DOUBT, RESEND_PENDING or FILE_REJECTED (REJECTED and IN_REPAIR do not block: a rejected record is resent as new, spec 9.5 and 10 rule 2) and, for a CANC, the latest earlier live version (delivery not REJECTED, IN_REPAIR, WITHDRAWN or WRITTEN_OFF) is a NEWT in ACCEPTED_PROVISIONAL or ACCEPTED_CONFIRMED; otherwise the CANC stays BLOCKED (status shows it; the exit to WITHDRAWN is P3d). Then assemble, gate, `Sealing.seal`, `Transport.send` with the gate `() -> sealing.beforeFirstByte(...) == CLEAR` (a holder keeps the PreSendStatus, read after `send` returns). From SENDING: DELIVERED gives AWAITING_ACK; FAILED_BEFORE_FIRST_BYTE gives QUEUED; ABORTED_BY_GATE with a refusal before the marker gives QUEUED (STALE_LEASE also stops the tick), with MARKER_REFUSED or an exception IN_DOUBT; UNKNOWN_OUTCOME gives IN_DOUBT; REJECTED_DUPLICATE gives IN_DOUBT with the DQ item SEND_ANOMALY code DUPLICATE_FILE_NAME and no resend; IN_DOUBT is never resent (I6). An L6 failure is recorded once per delivery (`RunRegistry.markL6Failed` and one DQ item L6_FAILED); the Sender skips a marked delivery on later ticks, later versions of its key stay waiting, status prints QUEUED L6_FAILED. Then poll, dedupe, parse, correlate, apply, then the horizon rule.
- **D-W10 Correlation.** The answer names the file (message id) and per record the executing LEI and TRN; the message id selects the delivery (the sender's map, cross-checked with `attempt(id).fileName()`); the record key must equal the business key `lei|trn`, else UNMATCHED_FEEDBACK.
- **D-W11 Every evidence object** is written through `EvidenceWriter.put(key, bytes, mediaType, retentionClass, objectClass)`: store put, `ManifestLedger.recordObjects` (hash of the plaintext), retention claim. When `evidence.get(key)` is present the stored bytes stay and the manifest and retention rows are completed from the stored hash: a replay writes nothing new and never fails with `EvidenceIntegrityException` or `ManifestConflictException` (SF1). `dq`, `validation` and `feedback` are plain namespaces (A8, A10, A11: objects stand in for rows) and hold fixed keys and codes only (`feedback` holds the raw answer bytes: executing LEI, TRN, codes).

> The home NCA and ARM, once known, replace the simulator profile.
