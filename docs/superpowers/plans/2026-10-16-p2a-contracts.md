## 2. The pack file contract (shared by T6 to T10 and T19)

```
packs/<id>/
  pack.yaml            id, semver, regime, jurisdiction, valid.legal.from[, to], as_at_field, engine_min,
                       input_schema (SHA-256 of the typed IR of model/canonical-input.yaml), [supersedes],
                       [limits: {rule_nodes, list_items, string_code_points, record_budget}], [imports: []],
                       reports: [ {id, input, scope_tables, [derive_tables], [validate], [lifecycle],
                       [endpoint_profiles], [legs]} ]
  model/canonical-input.yaml   variables: { <path>: {type: BOOL|INT|DECIMAL|STRING|TIMESTAMP|DATE|ENUM|LIST,
                                [enum: <name>], [source: EVENT|STATE], [optional: true]} }
  scope/*.yaml                   decision tables
  reasons.yaml  sources.yaml  rationales.yaml  [interpretations.yaml: absent or "pins: []"]
  derive/  lifecycle.yaml  route/  enrich/  validate/  endpoints/  refdata.yaml     strict-parsed, digested, NOT interpreted
  tests/golden/*.json   tests/authorship.yaml
  CHECKSUMS            "<64 hex>  <path>" per file, sorted, LF-normalised bytes; no ATTESTATION in P2a
```

- **Allowed paths** are exactly: the root files `pack.yaml reasons.yaml sources.yaml rationales.yaml interpretations.yaml lifecycle.yaml refdata.yaml CHECKSUMS ATTESTATION`; `model/canonical-input.yaml`; `scope/*.yaml`; `tests/authorship.yaml`; `tests/golden/*.json`; `*.yaml` under `derive/`, `route/`, `enrich/`, `validate/`, `endpoints/`. Any other path, including a `.json` outside `tests/golden/`, is `FILE_UNKNOWN`.
- **Validity windows.** `valid` accepts exactly the key `legal` with `from` and optional `to`; `supervisory`, `event` or any other key is `VALIDITY_WINDOW_RESERVED` (RSV-6). This holds in `pack.yaml` and in table rows.
- **Limits.** Each `limits` value is an ASCII decimal integer in 1 to the engine hard cap of `PackFormat` (T2), else `LIMITS_OUT_OF_RANGE`.
- **Legs.** The report-level `legs` is the report's closed leg vocabulary, a subset of MARKET, CLIENT, ALLOCATION, default all three; the IR emits the explicit vocabulary per report. A row-level `legs` entry outside the report's vocabulary is `ROW_LEG_NOT_IN_REPORT` (T9).
- **Cells.** Every string cell of a table row is ONE line of clean text: LF, CR, TAB and any `PackText` violation (T5) give `CELL_BAD_CHARACTER`, for `when` as well; no multi-line expression, no CRLF normalisation inside a cell. `source_id` and `rule_ref` match `[A-Za-z][A-Za-z0-9_.-]{0,63}`, so neither can start with `= + - @` or contain `# ; ,`.

Decision table file (every scalar is a string; the parser types explicitly):

```yaml
table: {id: sample.s0.scope, hit_policy: FIRST, priority: explicit, inputs: [event.kind], catch_all: S-DEFAULT}
rows:
  - id: S-N03-novation              # [A-Za-z][A-Za-z0-9_.-]{0,63}, unique in the pack
    node: N03                       # declared in reasons.yaml
    priority: 300                   # [1-9][0-9]{0,8}, unique in the table; ascending = evaluated first
    when: "event.kind in ['NOVATION','ASSIGNMENT']"
    outcome: DO_NOT_REPORT          # REPORT | DO_NOT_REPORT | REPORT_BY_OTHER | UNDETERMINED
    reason: SAMPLE.N03.EXCLUDED     # declared in reasons.yaml; its default outcome must equal the row's outcome
    rule_ref: RULE-0001             # optional, pack-unique (RULE_REF_DUPLICATE); same shape as ids
    cite: [{source_id: sample-law, provision_path: sample/1, role: BASIS}]    # at least one; resolves in sources.yaml
    rationale: RAT-0001             # resolves in rationales.yaml
    valid: {legal: {from: 2018-01-03}}   # [from, to) UTC dates; required except on the catch-all, which has none
    set: {action: NEWT}             # optional (BRK-10); names [a-z][A-Za-z0-9_.]*, values [A-Za-z0-9_.:/-]+
    legs: [MARKET]                  # optional, REPORT rows only, default [MARKET] (OI-2); within the report's legs
```

`reasons.yaml`: `prefix`, `nodes: [..]`, `reasons: [{code, label, category (EXCLUSION|INCLUSION|OUT_OF_SCOPE|DATA_QUALITY|DEFAULT), default_outcome, owner, valid: {from[, to]}}]`. `sources.yaml`: `sources: [{source_id, version, retrieved_at, content_sha256, [eli], provisions: [{path ([A-Za-z0-9_./:-]+), role, status (IN_FORCE|REPEALED|PROPOSED), [quote (at most 240 characters, a plan limit), quote_sha256 (SHA-256 of the quote as parsed)]}]}]`. `rationales.yaml`: `rationales: [{id: RAT-nnnn, text}]`. Golden case: the P0 JSON format with a **mandatory** `provenance` object (`{"kind":"CONSISTENCY_ONLY"}` while G1 is open). `tests/authorship.yaml`: `rules: {<row id>: <author id>}`, one entry per row.

## 3. The expression language contract (shared by T11 to T14)

Design basis: `spikes/spike-r/.../inhouse` (`Lexer`, `Parser`, `Ast`, `Evaluator`, `Library`, `StaticCost`) and `.../table/CompiledPack`. Read for design; write fresh, test-first.

- **Grammar** (lowest precedence first): ternary `c ? a : b`; `||`; `&&`; relations `== != < <= > >= in` (left-associative); `+ -`; `* /`; unary `! -`; postfix method call `x.name(args)`; primary: literal, `( e )`, list `[e, ...]`, path `a.b.c`, function call, `has(path)`. `has(path)` is one node: its path argument is not a node, but `paths()` includes it. Literals: 64-bit int; decimal (ASCII digits, a dot, digits; keeps its scale; at most 38 digits); string in `'` or `"` with escapes `\\ \' \" \n \r \t`; `true`, `false`. Refused at compile (`ExprException`, kind `PARSE`): `null`, exponent and hex literals, assignment, single `&` or `|`, loop macros (`all exists exists_one map filter`), user functions, unknown functions and methods, wrong arity, field access on a non-path, more than `maxNodes` nodes (checked while parsing), syntactic nesting above 100, tree depth above 256, and any path not declared in the `variables` map given to `compile`. Whitespace is space, tab, CR, LF only; no locale anywhere.
- **Typing** is dynamic (the type checker is P2b); the `ValueType` map only refuses undeclared paths. A clash is a `TYPE` error at evaluation.
- **Semantics.** int op int gives int, overflow is `OVERFLOW`; with a decimal operand the result is decimal (`INT_DECIMAL_MIX`, DECIDE D13); above 38 digits `SCALE`; int `/` int truncates; decimal `/` is exact or `NON_TERMINATING`; division by zero `DIV_ZERO`; `+` also joins strings and lists. `==` `!=`: same type; int with decimal numerically (so 1.10 equals 1.1); enum with enum by type and name; enum with string by name (S07: no ruling switch; a `TYPE_ERROR` alternative needs an enum literal in the grammar, so it is a plan amendment); lists elementwise; else `TYPE`. `< <= > >=`: numbers, strings by code point, timestamps, dates, else `TYPE`. `x in list` uses `==`; a non-list right side is `TYPE`. `&&` `||` go left to right and short-circuit; a non-bool operand is `TYPE`; **an error in an evaluated operand propagates** (`AND_LEFT_ERROR` and `OR_LEFT_ERROR`, DECIDE A04 and E06; the alternative absorbs as CEL does when the right operand decides). A declared path with no binding is `ABSENT` when read; `has(p)` is true iff bound (`HAS_BELOW_ABSENT`, DECIDE A07: default false; the alternative is `ABSENT` when a declared ancestor path of `p` is unbound). A ternary needs a bool condition. A string or list result longer than `string_code_points` / `list_items` is a `RANGE` error. For `+` (string and list) the check uses the operand sizes and comes after the charge and before the allocation; for `upper` and `lower` it comes after the operation (the operand is within the limit); a string literal longer than `string_code_points` is `PARSE`. The static worst case holds only because every operand is an input within the limits, a literal, or a capped result.
- **Library (names SPIKE-DESIGN, unfrozen; library version 1):** `dec(x)` (text or int to decimal), `round(d, places, 'HALF_UP'|'HALF_EVEN')` (places 0 to 38), `string(x)` (decimals as plain text without trailing zeros, timestamps as `isoMicros`, enums by name), `int(x)`, `timestamp(text)` (RFC 3339, seconds and offset mandatory, finer than a microsecond `RANGE`), `date(text)`, `isoMicros(ts)` (`yyyy-MM-ddTHH:mm:ss.ffffffZ`, years 0000 to 9999, written by hand), `dayOfWeek(date)`, `upper`, `lower` (`Locale.ROOT`), `size` (code points, or list items), `contains(x, y)`, methods `startsWith`, `endsWith`, `contains`. Identifier functions (LEI, ISIN, CFI, MIC) are P5; the **library version** (`Library.VERSION`) is what they will bump.
- **Errors.** `ErrorKind`: `ABSENT TYPE OVERFLOW DIV_ZERO NON_TERMINATING PARSE RANGE SCALE LOSSY OTHER`. `ExprException extends ExpressionException`, has `kind()`, carries no stack trace. A budget overrun is the port's `BudgetExceededException`, never an `ExprException`.
- **Cost model v1** (charged through the `CostMeter` **before** the work): 1 per node evaluated, on entry; plus the length of the list operand of `in` and `contains(list, x)`, whether or not an earlier item matches; plus both sizes for list `+`; plus `(code points of both) / 256` for string `+`; plus `code points / 256` per string argument of `upper lower size string int startsWith endsWith`; plus, for string `contains(x, y)` and its method form, `(cp(x) / 256 + 1) x (cp(y) / 256 + 1) - 1` (integer division; 288 at the default limits: 17 x 17 - 1; the library version stays 1); plus `1 + code points / 256` for `dec(text)`, `timestamp`, `date`; plus 1 for `round`, decimal `/` and `dec(non-text)`. Integer division floors.
- **Static worst case** of a rule (`InHouseExpression.Compiled.staticWorstCaseUnits()`): the sum over all nodes (taken or not) of 1 plus the surcharge bound above, every list bound at `list_items` (a list literal at its own length, also as a branch of a ternary: a ternary is bounded by the larger of its two branches; as built in T12) and every string at `string_code_points`; a property test shows runtime units never exceed it for inputs within the limits. **Per-record budget** (`PackBudget`) = `limits.record_budget` if declared, else 2 x the sum over all rows of (1 + static worst case). **Rule ceiling** = `limits.rule_nodes` (default 512) on the node count at compile.

## 5. Formats and rules that the tasks apply (moved here from the tasks to keep the plan within its size limit)

### 5.1 Replay compatibility and `engine_min` (T3)

**The rule (spec 6.3, "P2a defines the rule").** Two builds are replay-compatible iff they have the same `major` and the same `libraryVersion`; `minor` and `patch` never matter. `major` is bumped by any change that can alter a decision for the same pinned inputs (interpreter or table semantics, the cost model, any expression construct, a DECIDE ruling); `libraryVersion` by any change to a built-in function's behaviour or cost. A running engine **satisfies** an `engine_min` iff it has the same `major` and `libraryVersion` and (`minor`, `patch`) not below the minimum's: a pack never runs on another major or library version unless it is released again with a new `engine_min` (fail closed; provisional until G-S3b).

### 5.2 PackYaml/1 (T4)

**PackYaml/1:** one document; UTF-8 with LF (CRLF normalised first); block mappings and block sequences by indentation with spaces (a sequence item is a scalar, a one-line flow collection, or a block mapping that may start on the dash line; a sequence directly in a sequence is refused); one-line flow lists and flow mappings that nest; plain, single-quoted (`''` is a quote) and double-quoted scalars (escapes only `\\`, `\"`, `\n`); comments after `#` at line start or after a space, outside quotes; **every scalar is a string**; keys are plain (`[A-Za-z_][A-Za-z0-9_.-]*`) or quoted; a key with no value is an error, `''` is the empty string; an empty or comment-only file is an empty mapping.

### 5.3 Decision-table rules (T7)

The shape is the table block of section 2. Header keys exactly `id hit_policy priority inputs catch_all` (`hit_policy` `FIRST`, `priority` `explicit`); row keys `id node priority when outcome reason rule_ref cite rationale valid set legs`; `priority` `[1-9][0-9]{0,8}`; `outcome` an exact `Outcome` name (no case folding, so `report` is refused even under `tr_TR`); `node` `[A-Z][A-Z0-9]{0,7}`; ids, `source_id` and `rule_ref` `[A-Za-z][A-Za-z0-9_.-]{0,63}` (so none can start with `= + - @` or contain `# ; ,`); `provision_path` `[A-Za-z0-9_./:-]+`; `set` names `[a-z][A-Za-z0-9_.]*`, values `[A-Za-z0-9_.:/-]+`; `valid` exactly the key `legal` with `from` and optional `to` (`supervisory`, `event` or any other key is `VALIDITY_WINDOW_RESERVED`, RSV-6); `legs` only on REPORT rows (default `[MARKET]`, OI-2). **Every string cell of a row (id, node, when, reason, rule_ref, set names and values, cite parts, rationale, legs) must be ONE line of clean text**: LF, CR, TAB and any `PackText` violation give `CELL_BAD_CHARACTER`, for `when` as well; there are no multi-line expressions and no CRLF normalisation, and `TableCsv.importRows` goes through this parser, so a CSV import cannot bypass it (state this in the format notes). Rows are sorted by priority in the model. Codes are named by the tests, for example `CATCH_ALL_MISSING`, `CATCH_ALL_NOT_LAST`, `CATCH_ALL_NOT_UNDETERMINED`, `PRIORITY_DUPLICATE`, `ROW_NO_CITATION`, `WHEN_FORMULA_CHARACTER`, `CELL_BAD_CHARACTER`.

### 5.4 Loader order, reserved slots, canonical IR and digest (T9)

**Loader order (fail closed: a pack is returned only when `problems` is empty):** verify CHECKSUMS (`CHECKSUMS_MISSING` if absent); parse the manifest; parse `model/canonical-input.yaml` and compare the digest of its typed IR with `input_schema` (`INPUT_SCHEMA_DIGEST_MISMATCH`, the message carries `expected <64 hex>`); `as_at_field` must be a declared TIMESTAMP variable (`AS_AT_FIELD_INVALID`); every report's listed files exist (`REPORT_FILE_MISSING`) and every table passes `TableParser` and `TableChecks`; a file under `scope/` that no report lists is `FILE_UNREFERENCED`; registries parse and pass `RegistryChecks`; row ids are unique across the pack (`ROW_ID_DUPLICATE`) and so are `rule_ref` values (`RULE_REF_DUPLICATE`); a row `legs` entry outside its report's vocabulary is `ROW_LEG_NOT_IN_REPORT`; the allowed paths are exactly those of section 2, and any other path (a `.json` outside `tests/golden/`, anything else under `model/`: report schemas are P5 and P8) is `FILE_UNKNOWN`. **Reserved, accepted only empty:** `interpretations.yaml` absent or `pins: []` (`INTERPRETATIONS_RESERVED`); any file under `tests/properties/` is `PROPERTY_TESTS_RESERVED`. The `tests/properties/` check runs before the allowed-path check, so such a file reports `PROPERTY_TESTS_RESERVED`, not `FILE_UNKNOWN`. **Not interpreted** (`derive/`, `lifecycle.yaml`, `route/`, `enrich/`, `validate/`, `endpoints/`, `refdata.yaml`): strict-parsed (a `PackSyntaxException` becomes a problem with its code and line), digested, and one note `not interpreted by this engine build: <path>` each; the top-level keys of `lifecycle.yaml` must be in `business_key record_key trn identifiers status_model corrections successor_gate due_at provenance examples` (`provenance` and `examples` are accepted for the G1 labelling of fixtures and are not part of BRK-16) or be a named clock (a mapping with keys `anchor` and `offset`, `on_expiry` optional), else `LIFECYCLE_KEY_UNKNOWN` (BRK-16). An `ATTESTATION` file adds the note `attestation present, not verified (P9b)`. `state.*` variables with `source: STATE` are accepted (BRK-04). **IR** (numbers are `Long`, as `Json.canonical` requires): `{"formatVersion":1,"packId":...,"files":{<path>: <value>}}` over every file except `CHECKSUMS` and `ATTESTATION`; tables as typed maps (rows ascending by priority, `set` and `inputs` sorted, absent optionals omitted, REPORT `legs` explicit); each report's explicit leg vocabulary; registries as typed maps sorted by id; opaque YAML and golden JSON as generic trees. The digest therefore ignores comments, key order, row order, line endings and OS.

### 5.5 Conformance data (T14)

**The vectors are re-authored, not imported** (ids such as `T07` or `A04` are conformance vectors, not tasks). Start from the data of `spikes/spike-r/src/main/resources/semantic-vectors.tsv` (47 rows; expression text and bindings may be copied as data): drop `L01` (spec 6.2: no loops; a note stays in `rulings.tsv`), give every row a class and a basis, use the generic `ERR` instead of kind-specific errors for MUST and SHOULD rows, and apply the changes in the table. Format (UTF-8, LF, tab-separated): `id class expression bindings expected budget ceiling basis`. `bindings`: `;`-separated `path=type:value` items: `s:` string, `i:` int, `d:` decimal, `b:` bool, `t:` timestamp, `D:` date, `e:Type.NAME` enum, `l:<typed item>|<typed item>` list, `absent:<VALUETYPE>` (declared, unbound), with `@gen(n)` (a string of n characters or a list of n items) and `@chain(n)` (a sum of n ones) in an expression. `expected`: `T F i:<n> d:<dec> s:<text> t:<instant> ERR ERR:<KIND> COMPILE_ERROR ONEOF:<a>|<b> @ruling`.

| Class | Meaning | Rows (46) |
|---|---|---|
| MUST (12) | the quoted spec text fixes the value; no error kind, no dependence on a library spelling's details | D01 (decimal arithmetic, I3), D08 (`ERR`), D12 (no binary floating point, I3), A01, A02 (`ERR`), A03, A05, A06, A08 (explicit absence, 6.2, 7.5), S03 (the spec's own `in` example), E02 (`ERR`), T07 (no locale, I3) |
| SHOULD (19) | a sensible reading of the spec | D02, D03, D04, D05, D06, D10, T01, T02, T04, T05 (`ERR`), T08, S01, S02, S04, S05, S06, S08, E04 (`ONEOF:COMPILE_ERROR\|ERR`), E05 |
| DECIDE (5) | the spec is silent and layers differ; expected is `@ruling`, the value lives in `rulings.tsv` (S07: no alternative) | D13, A04, A07, E06, S07 |
| SPIKE-DESIGN (10) | the expectation is the spike's own choice (spelling, limit, error taxonomy, cost numbers); regression tests of the production design, never conformance | D07, D09, D11 (new expression `dec('1000000000000000000000000000000000000000')` expecting `ERR:SCALE`), T03, T06, E01, E03, C01, C02, C03 |

### 5.6 Table interpretation, OI-3 (T16)

**Interpretation (OI-3, provisional).** The program reads `as_at_field` from the bindings (a `TimestampValue`; missing or another type is `ExprException` `ABSENT` or `TYPE`) and takes its UTC date; it visits the tables in report order; in each table it walks the rows ascending by priority, **skips a row whose `valid` window does not contain that date** (no charge, no path step; the catch-all has no window) and for every other row: `meter.enter(row.id())`, charge 1, evaluate `when` (a non-bool result is `ExprException(TYPE)`), `trace.step(id, matched, units)`; the first match decides the table; if it is not the catch-all it is the decision, otherwise the next table is tried; if every table ended in its catch-all the decision is the last table's catch-all. An `ExprException` is rethrown as `RuleEvaluationException(rowId, e)` after remembering its kind. **`create`** refuses (IAE naming the cause) a pack that does not compile, whose canonical input `CanonicalBindings.checkSupported` rejects, or whose `engine_min` the running `EngineInfo.BUILD` does not `satisfy`. **`evaluate`** (design reading: `WalkingSkeletonRegime`): `Completed` becomes a `DecisionBody` with the row's outcome, reason and node, `ruleIdsHit` = the row id, the recorded path, citations resolved through the Legal Source Registry (`Citation(sourceId, path, role, quoteSha256)`), `legs` = the row's legs for REPORT else empty, `attributes` = the row's `set`, `asAt` = the as-at value (the event time if unreadable), `inputDigest` = `InputDigest.of(execution, ingestKey)`; `BudgetExhausted` and `Failed` become UNDETERMINED with reason `EXEC_BUDGET` or `EXEC_ERROR`, node `EXEC`, no rule hit, the recorded path, the citations of the **last table's catch-all** (I5), and flags `rule_id=<id>`, `cost_units=<n>`, `limit=<n>` (budget) or `rule_id`, `error_class=<class>`, `error_kind=<KIND>` when known, `cost_units` (error; spec 7.3). `decisionContext()` is `DecisionContext(pack digest, Optional.empty(), List.of(), List.of(), List.of(), "none", "none", EngineInfo.BUILD.toString(), executor.id())` (overlay, pins and Firm Profile are P2a-2).

### 5.7 CSV format and table YAML (T21)

**CSV format (provisional; the AT-8 round trip).** UTF-8, LF, no BOM, RFC 4180 quoting: a field is quoted iff it contains a comma, a double quote, LF or CR, or begins or ends with a space; a quote inside is doubled. One header row with exactly `id,node,priority,when,outcome,reason,rule_ref,cite,rationale,valid_from,valid_to,set,legs`; rows ascending by priority; an empty cell is an absent value; `cite` is `source_id#provision_path#ROLE` items joined by `;`, `set` is `name=value` items joined by `;` sorted by name, `legs` names joined by `;` (the charsets of T7 keep the separators unambiguous). **Import** accepts CRLF, an optional BOM, a missing final newline and any column order, but exactly the expected column set; the table header (`id`, `inputs`, `catch_all`) comes from the existing table; each row becomes the same node tree the YAML parser produces and goes through `TableParser` and `TableChecks`, so an import cannot bypass a check; extra codes `CSV_COLUMNS`, `CSV_QUOTE`, `CSV_CELL_COUNT`. **The CSV format forbids line breaks inside cells** (T7: LF, CR and TAB in any cell are `CELL_BAD_CHARACTER`), so the YAML writer needs only the escapes `\\` and `\"`. The table YAML is written in one canonical layout (keys in contract order; `when` and every non-plain-safe value double-quoted; `inputs`, `cite`, `set`, `legs` as flow collections); **comments in the original file are not preserved** (stated in the format notes).
